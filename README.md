# ระบบสำรวจที่พักและคำนวณระยะทางเพื่อจัดสรรสวัสดิการเดินทาง (MWater Delivery)

แอปพลิเคชันสำหรับสำรวจตำแหน่งที่พักปัจจุบันของพนักงานและผู้ประกอบการขนส่ง เพื่อคำนวณระยะทางจริงจากที่พักไปยังสาขาที่วิ่งงานประจำ และนำค่าใช้จ่ายค่าน้ำมันจริงมาใช้พิจารณาจัดสรรสวัสดิการช่วยเหลือ (เกณฑ์เริ่มต้น > 200 บาท)

---

  👉 `http://localhost:3000/dashboard.html`
  - **รหัสผ่านผู้จัดการ (ค่าเริ่มต้น):** `Mwater2026`

## ✨ ความสามารถหลักของระบบ

### 1. หน้าฟอร์มสำหรับพนักงาน (`/`)
- ออกแบบเฉพาะสำหรับเปิดผ่านหน้าจอมือถือ กรอกง่าย สบายตา
- ช่องกรอก: รหัสพนักงาน, ชื่อ-นามสกุล, เบอร์รถ/ทะเบียนรถ
- รายชื่อสาขาให้เลือกครบทั้ง **24 แห่ง** (สาขา, คลังสินค้า, โรงงาน)
- รองรับการวางลิงก์ที่แชร์จาก Google Maps (ทั้งลิงก์สั้น `maps.app.goo.gl` หรือลิงก์เต็ม)
- มีปุ่ม **"ตรวจสอบพิกัด"** เพื่อดูตำแหน่งบนแผนที่จำลองก่อนส่ง
- มีปุ่ม **"ดึงพิกัดจากตำแหน่งปัจจุบัน (GPS)"** สะดวกสำหรับคนขับที่เปิดฟอร์มขณะอยู่ที่พัก
- มีปุ่ม **"วิธีคัดลอกลิงก์"** พร้อมคำแนะนำ 4 ขั้นตอนอย่างชัดเจน
- เมื่อกดบันทึก ระบบจะแสดงระยะทางจริงที่คำนวณได้ให้คนขับทราบทันที

### 2. หน้าแดชบอร์ดสำหรับผู้จัดการ (`/dashboard.html`)
- **ระบบความปลอดภัย (PDPA):** ล็อกอินด้วยรหัสผ่านผู้จัดการ ป้องกันบุคคลภายนอกเข้าถึงข้อมูลส่วนตัว
- **การ์ดสรุปสถิติภาพรวม (KPI Cards):**
  - จำนวนรถทั้งหมดที่สำรวจ
  - จำนวนรถที่ค่าน้ำมันเกินเกณฑ์ (คัน)
  - สัดส่วนเปอร์เซ็นต์รถที่เกินเกณฑ์ (%) พร้อม Progress bar
  - ระยะทางเฉลี่ย (กิโลเมตร)
- **แถบควบคุมและคำนวณสด (Live Control Bar):**
  - **ตัวกรองรายสาขา:** เลือกดูภาพรวมทุกสาขา หรือเจาะจงเฉพาะสาขาใดสาขาหนึ่ง
  - **สลับโหมดคำนวณ:** ปุ่มคลิกสลับระหว่าง **"เที่ยวเดียว (ที่พัก ➔ สาขา)"** และ **"ไป-กลับต่อวัน (× 2)"** ได้ในคลิกเดียว
  - **ราคาน้ำมันดีเซล:** ปรับเปลี่ยนได้ตามราคาประกาศปัจจุบันในไทย (ค่าตั้งต้น 32.94 บาท/ลิตร)
  - **อัตราสิ้นเปลือง:** ปรับเปลี่ยนได้ (ค่าตั้งต้น 9.0 กม./ลิตร)
  - **เกณฑ์พิจารณาเงินช่วยเหลือ:** ปรับเปลี่ยนได้ (ค่าตั้งต้น 200.0 บาท)
  - *ทุกครั้งที่ปรับเปลี่ยนค่า ตัวเลขสรุป แผนที่ และตารางจะคำนวณใหม่แบบ Real-time ทันที*
- **แผนที่แสดงการกระจายตัว (Interactive Leaflet Map):**
  - หมุดสีน้ำเงิน = สาขา/คลังสินค้า/โรงงาน (24 แห่ง)
  - หมุดสีเขียว = รถที่ไม่เกินเกณฑ์
  - หมุดสีแดง = รถที่เกินเกณฑ์เงินช่วยเหลือ (> 200 บาท)
  - คลิกที่หมุดรถเพื่อดูข้อมูลคนขับ และระบบจะวาดเส้นประเชื่อมโยงไปยังสาขาที่วิ่งงานประจำ
- **ตารางข้อมูลรายบุคคล:**
  - ค้นหาตามรหัสพนักงาน ชื่อ ทะเบียนรถ หรือสาขา
  - แสดงระยะทาง, ค่าน้ำมัน, สถานะเกณฑ์ และลิงก์เปิดดูพิกัด
- **ส่งออกรายงาน Excel (.xlsx):**
  - คลิกปุ่ม **"ส่งออก Excel"** เพื่อดาวน์โหลดไฟล์รายงานสรุป จัดรูปแบบสวยงาม พร้อมนำเสนอผู้บริหารหรือการประชุม

## 🛠️ วิธีการเปิดเซิร์ฟเวอร์ (Commands)

เปิดหน้าต่าง PowerShell หรือ Command Prompt ที่โฟลเดอร์นี้ แล้วพิมพ์:

```bash
# เริ่มการทำงานของเซิร์ฟเวอร์
node src/server.js
```

หรือใช้คำสั่ง npm:

```bash
npm start
```

## 📁 โครงสร้างโปรเจกต์
- `src/db.js` : ตัวจัดการฐานข้อมูล SQLite ในตัว และระบบนำเข้าพิกัด 24 สาขาจาก KML
- `src/geo_utils.js` : ตัวแกะพิกัด Google Maps และคำนวณระยะทางตามถนนจริง OSRM
- `src/server.js` : Express API Server และตัวสร้างไฟล์ Excel
- `public/` : หน้าเว็บสำหรับพนักงาน (`index.html`) และแดชบอร์ด (`dashboard.html`)
- `survey.db` : ไฟล์ฐานข้อมูล SQLite จัดเก็บข้อมูลทั้งหมด
- `locations.kml` : ข้อมูลพิกัดสาขา คลังสินค้า และโรงงาน 24 แห่ง
